# Mengo Desktop v0.1.0 Preview Release Notes

This is the first OSS preview release candidate for Mengo Desktop.

## Highlights

- Local macOS memory powered by a bundled screenpipe recorder.
- Mengo Flow record -> synthesize -> review -> save loop.
- Runtime selection for Claude Code and Codex command shapes.
- Local preview mode, so OSS users can run without hosted Mengo account endpoints.
- Review edits now persist to generated `SKILL.md` and `flow.json`.
- Sign-out now stops recording and clears account state.
- Source picker subprocess failures now surface as errors instead of stale/empty data.
- Recorder start is idempotent to avoid duplicate helper processes.
- Global hotkey registration failures are surfaced in Flow UI.

## Install

Download:

```text
MengoDesktop-macos-arm64.zip
```

Unzip and move `MengoDesktop.app` to `~/Applications`.

This preview build is ad-hoc/local signed and not notarized. macOS may require right-click -> Open. A notarized Developer ID build is still a V1 release blocker.

## Requirements

- macOS 15 or later.
- Apple Silicon for this preview artifact.
- Screen Recording and Microphone permissions.
- Codex CLI or Claude Code CLI for Flow synthesis.

## Local Preview

Hosted account setup is optional in this OSS preview.

On first launch, click **Continue in local preview**. This creates a local Pro preview session with no hosted token, billing, or account-management handoff.

For command-line smoke tests:

```bash
MENGO_PREVIEW_ACCOUNT=pro swift run MengoDesktop
MENGO_PREVIEW_ACCOUNT=free swift run MengoDesktop
```

## Known Limitations

- Not notarized yet.
- Apple Silicon artifact only until x86_64 helper packaging is verified.
- Hosted account endpoints remain optional and are not required for local preview.
- Codex runtime requires manual smoke testing before being promoted as the default path.
- Legacy ScreenpipeMenu and ScreenpipeFlow targets remain in the repo during V1 cleanup.

## Upgrade Notes

Older ScreenpipeMenu/ScreenpipeFlow preview builds are separate legacy apps. Mengo Desktop installs as `MengoDesktop.app` and uses Mengo-specific logs under:

```text
~/Library/Logs/MengoDesktop
```

screenpipe data remains under:

```text
~/.screenpipe
```
