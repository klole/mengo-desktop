# Mengo Desktop v2.0.0 release checklist

## Automated verification

- [ ] `swift test`
- [ ] `swift build -c release --product MengoDesktop`
- [ ] `bash -n bootstrap-cert.sh build-mengo.sh install.sh scripts/release-mengo.sh`
- [ ] `plutil -lint Resources/MengoDesktopInfo.plist`
- [ ] `git diff --check`
- [ ] Secret scan reports no credentials or private recording data

## Product smoke test

- [ ] Fresh macOS user with no Mengo preferences opens directly to Memory
- [ ] Screen Recording and Microphone permission guidance is understandable
- [ ] Recorder starts, pauses, resumes, and stops without an orphan process
- [ ] Memory, Flow, Library, Studio, and Settings are functional
- [ ] Ollama runtime detects a missing model without downloading automatically
- [ ] Existing local Ollama model completes record → synthesize → review → save
- [ ] Review edits update `SKILL.md` and `flow.json`
- [ ] Studio saves timeline and canvas edits
- [ ] No account, upgrade, Pro, paywall, or unfinished UI appears

## Signed release

- [ ] Developer ID Application certificate is installed
- [ ] `notarytool` keychain profile is configured
- [ ] `MENGO_SIGN_IDENTITY='Developer ID Application: …' MENGO_NOTARY_PROFILE='…' scripts/release-mengo.sh`
- [ ] Extract the ZIP and run `codesign --verify --deep --strict MengoDesktop.app`
- [ ] Run `spctl --assess --type execute --verbose=2 MengoDesktop.app`
- [ ] Stapled ZIP installs and launches on a clean Mac without Gatekeeper warnings
- [ ] SHA-256 in `MengoDesktop.zip.sha256` matches the uploaded ZIP

## Publication (separate authorized phase)

- [ ] Review the complete local diff and create intentional commits
- [ ] Push `main`
- [ ] Tag `v2.0.0`
- [ ] Upload `MengoDesktop.zip` and `MengoDesktop.zip.sha256`
- [ ] Confirm README installation instructions and release notes
