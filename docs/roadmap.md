# Roadmap

This roadmap tracks the public V1 work for Mengo Desktop. The detailed release plan lives in `docs/release/mengo-desktop-v1-release-plan.md`.

## V1

- Public repo identity cleanup.
- Passing MengoDesktop build and tests in CI.
- Clear installer and release artifact names.
- Local Memory flow.
- Flow recording, synthesis, review, save, and delete.
- Codex runtime smoke test and setup docs.
- Claude Code runtime support where configured.
- Sign-out stops recording.
- Review edits persist to generated skill files.
- Privacy and security documentation.
- Manual V1 smoke test checklist.

## Post-V1

- Studio section.
- Hosted account and billing integration if the hosted product remains part of the roadmap.
- Homebrew cask.
- Broader architecture packaging if universal helper builds are not feasible.
- Richer skill editor with structured step editing.
